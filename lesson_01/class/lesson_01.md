# Занятие 1. Структура программы и переменные

**Дисциплина:** МДК.01.05 «Основы программирования на языке C++»  
**Группа:** 9/2-РПО-25/1 · **Стандарт:** C++17 · **Среда:** Visual Studio

На занятии разбираем устройство консольной программы, вывод текста, создание целочисленных переменных и изменение их значений. Практическая задача — дополнить карточку студента возрастом, номером пары и количеством выполненных заданий.

## 1. От исходного кода к результату

Исходный код хранится в текстовом файле с расширением `.cpp`, например `main.cpp`. Сборка включает обработку директив препроцессора, компиляцию исходного текста и компоновку. После успешной сборки появляется исполняемая программа, которую можно запустить и увидеть результат в консоли.

Порядок проверки каждого примера:

1. Предположить результат.
2. Изменить код и сохранить файл.
3. Собрать проект и запустить программу без отладчика через **Ctrl+F5**.
4. Сравнить фактический вывод с предположением.

При ошибке сборки сначала исправляют её причину, затем повторяют сборку. Нужно проверять имя проекта и полный путь открытого файла, чтобы запускать нужную программу.

## 2. Каркас программы

```cpp
#include <iostream>

int main()
{
    std::cout << "C++ lesson 1\n";
    std::cout << "Group: 9/2-RPO-25/1\n";
    return 0;
}
```

Вывод:

```text
C++ lesson 1
Group: 9/2-RPO-25/1
```

| Элемент | Назначение |
| --- | --- |
| `#include <iostream>` | Директива препроцессора: подключает стандартный заголовок со средствами ввода и вывода. |
| `int main()` | Главная функция программы; `int` — тип возвращаемого значения, `()` — используемая здесь форма без параметров. |
| `{` и `}` | Ограничивают тело функции. |
| `std::cout << ...;` | Инструкция вывода. |
| `;` | Завершает инструкцию вывода или возврата. |
| `return 0;` | Завершает `main` и возвращает среде запуска код успешного завершения. |

После директивы `#include` точка с запятой не нужна. После закрывающей скобки тела функции её также не ставят. Отступы, например четыре пробела, помогают видеть вложенность кода.

Достижение конца `main` тоже соответствует возврату нуля, но в учебных примерах оставляем явное `return 0;`.

Короткие фрагменты из следующих разделов нужно помещать **внутрь существующего `main`, до `return 0;`**. Полные программы запускают отдельно или заменяют ими содержимое исходного файла.

## 3. Вывод текста

`std::cout` — стандартный поток вывода; при обычном консольном запуске текст появляется в консоли. Префикс `std::` указывает пространство имён стандартной библиотеки. Оператор `<<` передаёт следующий фрагмент в поток.

Текст в двойных кавычках — **строковый литерал**. Кавычки ограничивают его в исходном коде, а `\n` внутри литерала задаёт перевод строки. Пробелы также нужно указывать явно.

```cpp
std::cout << "Name: ";
std::cout << "Alex\n";
std::cout << "Course: " << "C++\n";
```

```text
Name: Alex
Course: C++
```

Первые две инструкции формируют одну строку: первая не содержит перевода строки. Расположение инструкций на разных строках исходника само по себе не переносит текст в консоли.

## 4. Комментарии

Комментарии поясняют назначение данных и действий. Сами по себе они ничего не выводят.

```cpp
// Print the student card
std::cout << "Student: Alex\n";

/* Course information
   for the first lesson */
std::cout << "Course: C++\n";
```

- `//` — однострочный комментарий до конца строки.
- `/* ... */` — многострочный комментарий; такие комментарии не вкладывают друг в друга.
- Внутри строкового литерала слеши являются частью текста.

**Мини-практика:** вывести своё имя латиницей, группу и название дисциплины отдельными строками; добавить осмысленный комментарий. Затем временно удалить `;` у одной инструкции и собрать проект. Найти первое сообщение об ошибке, проверить указанную и предыдущую строки, восстановить символ и повторить сборку.

## 5. Переменная, тип и значение

**Переменная** хранит данные, к которым программа обращается по имени.

```cpp
int completedTasks{2};
std::cout << "Completed: " << completedTasks << "\n";
```

Здесь `int` — целочисленный тип, `completedTasks` — имя переменной, `2` — начальное значение. Число, записанное непосредственно в коде, является литералом. Обращение по имени при выводе даёт текущее значение переменной.

Кавычки меняют смысл записи:

```cpp
std::cout << "completedTasks\n";  // Text
std::cout << completedTasks << "\n";  // Variable value
```

```text
completedTasks
2
```

### Имена переменных

В учебных работах используем латинские буквы, цифры и подчёркивание; первым символом выбираем букву. Имя должно объяснять смысл данных. Для составных имён придерживаемся стиля **lowerCamelCase**: `studentAge`, `completedTasks`, `lessonNumber`.

| Запись | Оценка | Причина |
| --- | --- | --- |
| `studentAge` | Подходит | Имя описывает данные. |
| `tasks2` | Подходит | Цифра стоит после буквы. |
| `2tasks` | Ошибка | Имя начинается с цифры. |
| `student-age` | Не является одним именем | Дефис воспринимается как минус. |
| `int` | Ошибка | Ключевое слово языка. |
| `score` и `Score` | Разные допустимые имена | Регистр учитывается. |
| `__count` | Не использовать | Сочетание двойного подчёркивания зарезервировано. |

Пробелы внутри имён недопустимы. Имена с начальным подчёркиванием в учебных работах не используем: в языке есть зарезервированные сочетания подчёркиваний.

## 6. Объявление и инициализация

В этом занятии рассматриваем определения обычных локальных переменных внутри `main`. Запись `int taskCount;` создаёт переменную; в учебной речи также говорят «объявили переменную». **Инициализация** задаёт начальное значение при её создании.

Три формы инициализации:

```cpp
int lessonNumber = 1;
int studentAge(16);
int taskCount{5};
```

Для этих целых значений все три формы задают указанные числа. В дальнейшей практике используем фигурные скобки. В материале Metanit форма с круглыми скобками называется функциональной нотацией.

Пустые фигурные скобки задают целочисленной переменной ноль:

```cpp
int attempts{};
std::cout << "Attempts: " << attempts << "\n";
```

```text
Attempts: 0
```

### Значение нужно записать перед чтением

Обычная локальная переменная `int attempts;` не получает гарантированного начального числового значения. В C++17 чтение такой неинициализированной переменной приводит к **неопределённому поведению**. Нельзя рассчитывать ни на конкретное число, ни на обязательную диагностику.

Предпочтительно задавать значение сразу. Допустимо и отдельное присваивание до первого чтения:

```cpp
int attempts;
attempts = 1;
std::cout << "Attempts: " << attempts << "\n";
```

### Польза фигурных скобок

`int` хранит целые числа. Следующий фрагмент — **намеренная ошибка**, требующая диагностики сужающего преобразования в C++17:

```cpp
int taskCount{4.5};
```

После проверки нужно заменить `4.5` на `4`. Для данных с дробной частью далее используют подходящий тип, например `double`.

### Несколько переменных

```cpp
int first{2}, second{3};
std::cout << first << " " << second << "\n";
```

Результат — `2 3`. В первых работах удобнее определять каждую переменную отдельной строкой. Повторное определение того же имени в одном блоке вызывает ошибку.

## 7. Присваивание и порядок выполнения

**Присваивание** записывает новое значение в уже существующую переменную. Сначала вычисляется значение справа от `=`, затем оно сохраняется в переменной слева. Повторно указывать тип не нужно.

```cpp
#include <iostream>

int main()
{
    int completedTasks{};
    std::cout << "Before: " << completedTasks << "\n";

    completedTasks = 3;
    std::cout << "After: " << completedTasks << "\n";
    return 0;
}
```

```text
Before: 0
After: 3
```

`int completedTasks{};` создаёт переменную и инициализирует её нулём. `completedTasks = 3;` изменяет значение существующей переменной. Инструкции выполняются последовательно, поэтому вывод до и после присваивания различается.

### Трассировка значений

Трассировка — пошаговое отслеживание состояния переменных. Вначале полезно предсказать значения на бумаге, а затем проверить запуском.

```cpp
int score{4};
int savedScore{score};
score = 7;
savedScore = score;
score = 9;
std::cout << score << " " << savedScore << "\n";
```

Заполненная таблица для проверки:

| После инструкции | `score` | `savedScore` |
| --- | --- | --- |
| `int score{4};` | 4 | Ещё не создана |
| `int savedScore{score};` | 4 | 4 |
| `score = 7;` | 7 | 4 |
| `savedScore = score;` | 7 | 7 |
| `score = 9;` | 9 | 7 |

Вывод: `9 7`. При инициализации `savedScore{score}` копируется текущее значение. Последующее изменение `score` само по себе не меняет `savedScore`; для копирования нового значения нужно отдельное присваивание.

## 8. Самостоятельная работа «Карточка учебной работы»

В исходном задании предлагается продолжить первую практику в `practice/01-hello-cpp/main.cpp` личного репозитория. Это путь из учебного шаблона; в этом репозитории для работы на занятии предусмотрена папка `lesson_01/class/`.

Требования:

1. Вывести приветствие, своё имя латиницей и группу `9/2-RPO-25/1`.
2. Создать внутри `main` три переменные типа `int`: `studentAge`, `lessonNumber`, `completedTasks`.
3. Задать возраст целым числом, номер пары — единицей, количество заданий — нулём через пустые фигурные скобки.
4. Вывести возраст, номер пары и начальное количество выполненных заданий.
5. Отдельной инструкцией присвоить `completedTasks` значение `3`.
6. Вывести новое количество заданий под отдельной подписью.
7. Добавить осмысленный комментарий и проверить сборку и запуск.

Пример ожидаемого вывода:

```text
Hello, C++!
Name: Alex
Group: 9/2-RPO-25/1
Age: 16
Lesson: 1
Completed before: 0
Completed after: 3
```

Сначала добавить переменные и один вывод, проверить запуск, затем дописать остальные строки и присваивание. Нужно уметь объяснить, почему количество заданий выводится дважды с разными значениями.

**Дополнительно:** создать `savedTasks` со значением из `completedTasks` до изменения последней переменной и вывести сохранённое значение в конце. Перед запуском предсказать результат. На трёх отдельных целочисленных переменных показать три формы инициализации.
